Day 17 Assignment - Date Functions

Objective

Practice SQL Date Functions to understand how to retrieve and manipulate date and time values.

---

Questions

Q1

Display the current date.

Q2

Display the current date and time.

Q3

Display the current year.

Q4

Display the current month number.

Q5

Display the current day number.

Q6

Display the current day name.

Q7

Display the current month name.

Q8

Display only the date from the current date and time.

Q9

Display the current year, month and day in a single query.

Q10

Display the current date, day name and month name.

---

Concepts Covered

- CURDATE()
- NOW()
- YEAR()
- MONTH()
- DAY()
- DAYNAME()
- MONTHNAME()
- DATE()

---

Learning Outcomes

After completing this assignment, you should be able to:

- Retrieve the current system date and time.
- Extract year, month and day from a date.
- Display day and month names.
- Extract the date portion from a DATETIME value.
- Use multiple date functions in a single SQL query.
