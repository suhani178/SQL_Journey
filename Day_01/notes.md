---

Data

Data is raw facts and figures.

Examples:

- Rahul
- 101
- 20

---

Information

Information is processed and meaningful data.

Example:

- Average Marks = 80

---

Database

A database is an organized collection of related data.

Examples:

- College Database
- Hospital Database
- Banking Database

---

DBMS

DBMS (Database Management System) is software used to manage databases.

Examples:

- MySQL
- Oracle
- PostgreSQL
- SQL Server

---

RDBMS

RDBMS (Relational Database Management System) stores data in related tables and supports relationships between tables.

---

Table

A table stores data in rows and columns.

Example:

EMPNO| ENAME| JOB
101| Rahul| Developer
102| Amit| Analyst

---

Row

A row represents one complete record in a table.

---

Column

A column represents one attribute of a table.

Examples:

- EMPNO
- ENAME
- JOB

---

First SQL Query

SELECT * FROM EMP;

Explanation:

- SELECT → Retrieve data
- * → All columns
- FROM → Source table
- EMP → Table name
