# Day 1 Assignment

## Q1. Difference between Data and Information

Data is raw facts and figures.

Information is processed and meaningful data.

## Q2. What is a Database?

A database is an organized collection of related data.

## Q3. What is DBMS?

DBMS is software used to manage databases.

## Q4. What is RDBMS?

RDBMS stores data in related tables.

## Q5. What is a Table?

A table stores data in rows and columns.

## Q6. What is a Row?

A row is a complete record.

## Q7. What is a Column?

A column is an attribute of a table.

## Q8. Explain:

SELECT * FROM EMP;

This query displays all records and all columns from the EMP table.
