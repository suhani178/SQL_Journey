Day 20 Assignment - SQL Problem Solving & Interview Practice

Objective

Solve real-world SQL problems by applying the concepts learned from Day 1 to Day 19.

---

Questions

Q2

Q3

Q4

Q5

Q6

Display employee names and department names.

Q7

Q8

Q9

Q10

Q12

Display employees earning the minimum salary in their department.

Q13

Display department names having employees.

Q14

Display department names having no employees.

Q15

Q16

Q17

Q18

Q20

Learning Outcomes

After completing this assignment, you should be able to:

- Write SQL queries without referring to notes.
- Solve interview-style SQL problems.
- Select the correct JOIN for a given problem.
- Apply aggregate functions with GROUP BY and HAVING.
- Use subqueries and correlated subqueries confidently.
- Use SQL string, date and numeric functions effectively.
