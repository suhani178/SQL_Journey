Day 22 Assignment - SQL Constraints

Objective

Learn how to apply SQL constraints to maintain data integrity and enforce rules while creating tables.

---

Questions

Q1

Create an "EMPLOYEE" table where "EMPNO" cannot be NULL.

Q2

Create an "EMPLOYEE" table where "EMAIL" must contain unique values.

Q3

Create an "EMPLOYEE" table with "EMPNO" as the PRIMARY KEY.

Q4

Create a "DEPARTMENT" table with "DEPTNO" as the PRIMARY KEY.

Q5

Create an "EMPLOYEE" table with "DEPTNO" as a FOREIGN KEY referencing the "DEPARTMENT" table.

Q6

Create an "EMPLOYEE" table where "AGE" must be greater than or equal to 18.

Q7

Create an "EMPLOYEE" table where "CITY" has a default value of 'Kolkata'.

Q8

Create an "EMPLOYEE" table using both PRIMARY KEY and NOT NULL constraints.

Q9

Create an "EMPLOYEE" table using PRIMARY KEY, UNIQUE, and CHECK constraints together.

Q10

Create an "EMPLOYEE" table using all the following constraints:

- PRIMARY KEY
- NOT NULL
- UNIQUE
- FOREIGN KEY
- CHECK
- DEFAULT

---

Concepts Covered

- NOT NULL
- UNIQUE
- PRIMARY KEY
- FOREIGN KEY
- CHECK
- DEFAULT

---

Learning Outcomes

After completing this assignment, you should be able to:

- Apply constraints while creating tables.
- Differentiate between PRIMARY KEY and UNIQUE.
- Create relationships using FOREIGN KEY.
- Validate data using CHECK constraints.
- Assign default values using DEFAULT.
- Design tables with proper data integrity.
