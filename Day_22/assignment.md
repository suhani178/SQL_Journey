
Day 22 Assignment - SQL Constraints

Objective

Practice using SQL Constraints to ensure data accuracy, consistency, and integrity.

---

Questions

Q1

Create an "EMPLOYEE" table with "EMPNO" as the PRIMARY KEY.

Q2

Create an "EMPLOYEE" table where "ENAME" cannot be NULL.

Q3

Create an "EMPLOYEE" table where "EMAIL" must be UNIQUE.

Q4

Create a "DEPARTMENT" table with "DEPTNO" as the PRIMARY KEY, then create an "EMPLOYEE" table with "DEPTNO" as a FOREIGN KEY.

Q5

Create an "EMPLOYEE" table where "AGE" must be 18 or above using the CHECK constraint.

Q6

Create an "EMPLOYEE" table where the default value of "CITY" is 'Kolkata'.

Q7

Write a table definition that uses PRIMARY KEY, NOT NULL, and UNIQUE constraints together.

Q8

Write a table definition that uses all six constraints:

- PRIMARY KEY
- NOT NULL
- UNIQUE
- FOREIGN KEY
- CHECK
- DEFAULT

Q9

What is the difference between PRIMARY KEY and UNIQUE? Give one example of each.

Q10

Explain the purpose of the following constraints with one example each:

- NOT NULL
- PRIMARY KEY
- FOREIGN KEY
- CHECK
- DEFAULT

---

Concepts Covered

- NOT NULL
- UNIQUE
- PRIMARY KEY
- FOREIGN KEY
- CHECK
- DEFAULT

---

Learning Outcomes

After completing this assignment, you should be able to:

- Apply constraints while creating tables.
- Explain the purpose of each constraint.
- Create relationships between tables using FOREIGN KEY.
- Validate data using CHECK constraints.
- Design database tables with proper data integrity.
