## Key Learnings

- GROUP BY creates groups.
- HAVING filters groups.
- INNER JOIN returns matching rows.
- LEFT JOIN returns all rows from left table.
- RIGHT JOIN returns all rows from right table.
- Subqueries can be used inside WHERE clause.
- IN is used when subquery returns multiple values.
- EXISTS checks whether matching rows exist.
- Correlated subqueries depend on the outer query.
- E.DEPTNO links inner and outer queries.
