Day 21 Assignment - SQL Views

Objective

Learn how to create, use, modify, and delete SQL Views.

---

Questions

Q1

Create a view named "EMP_VIEW" that displays employee names and salaries.

Q2

Display all records from "EMP_VIEW".

Q3

Create a view named "HIGH_SALARY" that displays employees whose salary is greater than 3000.

Q4

Display all records from "HIGH_SALARY".

Q5

Create a view that displays employee names and department numbers.

Q6

Modify "EMP_VIEW" to display employee name, salary, and department number.

Q7

Create a view named "HR_EMPLOYEES" that displays employees working in the HR department.

Q8

Display all records from "HR_EMPLOYEES".

Q9

Delete the "HIGH_SALARY" view.

Q10

Delete the "EMP_VIEW" view.

---

Concepts Covered

- CREATE VIEW
- SELECT from a View
- CREATE OR REPLACE VIEW
- DROP VIEW

---

Learning Outcomes

After completing this assignment, you should be able to:

- Create SQL Views.
- Retrieve data from Views.
- Modify existing Views.
- Delete Views.
- Understand where and why Views are used.
